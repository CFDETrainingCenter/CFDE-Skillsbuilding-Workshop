# CFDE Skillsbuilding Workshop Content

Practical Skills for Omics Research Using CFDE Data and Resources:
The two-day workshop is designed to provide hands-on training and foundational knowledge on accessing and analyzing varying types of omics data (e.g., genomics, proteomics, transcriptomics) within the CFDE ecosystem. The workshop aims to support students, trainees, and researchers in developing practical technical skills while increasing awareness of CFDE resources, tools, and best practices for FAIR data use.
